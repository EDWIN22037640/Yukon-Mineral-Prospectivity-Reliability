# Evaluación de la confiabilidad de modelos de prospectividad mineral en Yukón, Canadá

Código, reconstrucciones PCA, validación espacial y análisis de incertidumbre desarrollados para evaluar la confiabilidad de modelos de aprendizaje automático en la prospección mineral. Investigación basada en datos publicados por Mantilla-Dulcey et al. (2024), con desarrollos propios V5 y V6.
